# 3D Model Library

stl-sherpa catalogs local 3D model files, renders previews, and helps organize files without moving them out of their libraries.

## Language

**Collection**: A named view of files in one library. A collection is either manual or smart.

**Manual Collection**: A collection whose membership and order are stored explicitly.

**Smart Collection**: A collection whose membership is derived from saved filter rules.

**Collection Query**: The resolved membership filters and ordering rules used to list files from either a manual or smart collection.

Avoid "smart query" when referring to resolved collection membership. A smart query is only the stored rule set.
